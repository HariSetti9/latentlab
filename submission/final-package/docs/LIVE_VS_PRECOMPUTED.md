# Live vs Precomputed Inventory

| Item | Classification | Provenance / use |
|---|---|---|
| Recurrent engine | LIVE COMPUTATION | Runs in browser from current puzzle/depth |
| BFS oracle | LIVE COMPUTATION | Separate algorithm on current puzzle |
| Grid, trace, depth comparison | LIVE COMPUTATION | Rendered from current engine output |
| Research claims | PUBLISHED RESULT | Cited author papers; not reproduced |
| Research diagram | EDUCATIONAL ILLUSTRATION | Original simplified HTML/CSS synthesis |
| Evaluation JSON/CSV/metrics | PRECOMPUTED BUT REPRODUCIBLE | Regenerated by evaluator |
| Preset verification | PRECOMPUTED BUT REPRODUCIBLE | Regenerated from engine output |
| Checksums | REGENERATABLE LOCAL ARTIFACT | SHA-256 over evidence and sources |
| Reproduction report | REGENERATABLE LOCAL ARTIFACT | Environment-specific and not hashed |
| QA screenshots | PRECOMPUTED BUT REPRODUCIBLE | Visual review; not scientific measurement |

The application never reads committed evaluation artifacts to determine live outcomes.
