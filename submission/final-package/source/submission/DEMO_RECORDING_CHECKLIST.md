# Demo Recording Checklist

## Before recording

- [ ] Use the Phase 9 production URL in a signed-out browser profile.
- [ ] Set viewport near 1440 x 900 and browser zoom to 100%.
- [ ] Disable notifications, chat popups, password prompts, extensions, and OS focus banners.
- [ ] Close private tabs/files and hide bookmarks if they reveal personal information.
- [ ] Confirm microphone input, room noise, gain, and a 10-second test playback.
- [ ] Load `?fixture=depth-matters-winding&depth=4` and scroll to the intended opening frame.
- [ ] Confirm the production build has no dev overlay, console error, or visible development-host URL.
- [ ] Keep depth 6, limitation, evidence, sandbox, self-check, and README tabs/anchors ready.

## During recording

- [ ] Speak at a calm 125-140 words per minute; pause after the depth 4/6 contrast.
- [ ] Move the cursor deliberately and keep it away from text being read.
- [ ] Show the BFS card and always-visible independence note; do not claim a nonexistent disclosure control.
- [ ] Select limitation and depth 16; state fixed-point saturation, not degradation.
- [ ] Call BDH/BDH-CQ a conceptual connection, not a reproduction.
- [ ] Do not call the operation proxy FLOPs, time, tokens, energy, price, or universal efficiency.

## After recording

- [ ] Watch the complete export with audio, captions, cursor, and text legibility checked.
- [ ] Confirm duration is within organizer rules and the first 60 seconds carry the core lesson.
- [ ] Export a backup master and a submission copy; keep the backup recoverable.
- [ ] Upload, open the video in a signed-out/private session, and verify playback without permission requests.
- [ ] Insert the final URL in README and `submission/FINAL_LINKS.md`.
- [ ] Run `pnpm verify:release` after every final URL is inserted.
